# 🎥 ConnectHub – Real-Time Video Conferencing Platform

A modern full-stack real-time video conferencing platform built using the MERN Stack. The application enables secure user authentication, HD video/audio meetings, screen sharing, meeting history, and seamless peer-to-peer communication using WebRTC and Socket.IO.

---

## 🚀 Features

- 🔐 Secure User Authentication (JWT)
- 🎥 Real-Time Video & Audio Calling
- 👥 Unique Meeting ID Generation
- 🖥️ Screen Sharing
- 🎙️ Audio & Video Controls (Mute/Unmute & Camera On/Off)
- 📜 Meeting History
- ⚡ Peer-to-Peer Communication (WebRTC)
- 🔄 Real-Time Signaling using Socket.IO
- 🛡️ Protected Routes with JWT Authentication
- ☁️ MongoDB Database Integration
- 📱 Responsive User Interface

## ⚙️ Installation

### Project Repository

```bash
git clone https://github.com/rutujabhavar/ConnectHub---Real-Time-Video-Conferencing-platform.git
```

### Move into the Project Folder

```bash
cd ConnectHub---Real-Time-Video-Conferencing-platform
```

### Backend Setup

```bash
cd backend
npm install
npm start
```

### Frontend Setup

```bash
cd frontend
npm install
npm start
```

---

## 🔑 Environment Variables

Create a `.env` file inside the **backend** folder.

```env
MONGO_URL=your_mongodb_connection_string
JWT_SECRET=your_secret_key
PORT=3001
CLIENT_URL=http://localhost:3000
```
